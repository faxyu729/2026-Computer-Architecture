# report/

各 Checkpoint 報告，格式依 HOMEWORK.md 第 5.3 節（六段式）：

1. 本次目標
2. 設計內容
3. 結果與分析
4. 遭遇的問題與解法
5. 白話說明
6. AI 使用說明

| 檔案 | 對應 CP | 內容 |
|---|---|---|
| `CP1.md` | CP1 | C baseline 報告 |
| `CP2.md` | CP2 | RV32IM 實作與指令統計報告 |
| [CP3.md](CP3.md) | CP3 | 六段式主報告：語意、編碼、三組範例、指令數比較與限制；AI紀錄待組員確認 |
| `cp2-b/` | CP2 | 測試紀錄（任務 B：編譯與模擬） |
| `cp2-c/` | CP2 | 指令統計原始資料（任務 C：指令統計） |
| [cp3-b/](cp3-b/README.md) | CP3 | B：R-type欄位與機器碼手算、三組範例、`.insn`組譯原始碼及objdump紀錄 |
| [cp3-c/](cp3-c/README.md) | CP3 | C：靜態／動態指令數比較、減少比例、比較範圍與假設 |
| `figures/` | — | 報告用圖表 |
